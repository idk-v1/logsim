instructions:
00 nop              []                        []
01 halt             []                        []   (sends signal into the void)
02 jump             [rom addr]                [pc]
03 jumpifzero       [rom addr, flag zero]     [pc]
04 jumpifless       [rom addr, flag less]     [pc]
05 jumpifgreater    [rom addr, flag greater]  [pc]
06 jumpifequal      [rom addr, flag equal]    [pc]
07 jumpifoverflow   [rom addr, flag overflow] [pc]
08 add              [regA, regB]              [regA, flag overflow, flagzero]
09 subtract         [regA, regB]              [regA, flag overflow, flagzero]
0A increment        [regC]                    [regC, flag overflow, flagzero]
0B decrement        [regC]                    [regC, flag overflow, flagzero]
0C multiply         [regA, regB]              [regA (low), regB (high), flagzero]
0D negate           [regA]                    [regA]
0E lshift           [regA]                    [regA]
0F rshift           [regA]                    [regA]
10 rshift(signed)   [regA]                    [regA]
11 lcycle           [regA]                    [regA]
12 rcycle           [regA]                    [regA]
13 xor              [regA, regB]              [regA]
14 and              [regA, regB]              [regA]
15 or               [regA, regB]              [regA]
16 invert           [regA]                    [regA]
17 compare          [regA, regB]              [flags less, greater, equal, zero]
18 readflagzero     [flag zero]               [regD]
19 readflagequal    [flag equal]              [regD]
1A readflagless     [flag less]               [regD]
1B readflaggreater  [flag greater]            [regD]
1C readflagoverflow [flag overflow]           [regD]
1D readpc           [pc]                      [regD]
1E memmove          [mem addr src]            [mem addr dest]
1F move             [reg addr src]            [reg addr dest]
20 load             [mem addr src]            [reg addr dest]
21 store            [reg addr src]            [mem addr dest]
22 loadimm          [imm*]                    [reg addr dest]    (* converted to rom addr)

flags: zero, equal, less, greater, overflow

registers A and B for most operations
register C for increment/decrement
register D for reading flags/pc

only 2 registers are needed for all math operations including both input and output
1 is needed for program counter
1 memory cell is for overflow
more registers can be created for general purpose use

- all memory cells are the same type, so you could technically use any memory cell as a register.
- registers are supposed to be fast, so mine need to be fast.
- addressing a memory cell adds 3 extra cycles to read and write, 
   so special hardware for accessing specific registers cuts off those extra 3 cycles.
- and some operations need to access 2 values at once, and the memory line doesn't support that,
   so fixed inputs and outputs are needed
- maybe 3 cycles isnt bad compared to the cost of most operations, 
   so addressing could be better (fewer instructions, plus only 1 move instruction).
   still would need a fixed input/output for operations (fake register bc they're all the same)
